Automatic save to a folder

Choose a folder (for example a folder on a USB drive, or Documents\SARP YED). Each time you reopen the form, click Choose save folder and pick the same folder again; Chrome opens it for you. After every save, edit or delete the form writes two files there automatically: SARP_YED_autosave_<device>.json (the full backup, used to restore) and SARP_YED_capture_<device>_latest.xlsx (the Excel file). The previous backup is kept as …_previous.json. Works in Chrome or Edge on a computer.

Paper fallback

If the laptop fails during a session, print this blank form in advance and capture on paper. Enter the paper forms into this form later; write the capture reference on each paper form once entered.

Export to Excel

Downloads an Excel workbook (.xlsx) with three sheets: Applicants, Existing resources and Required resources. Resource rows carry the capture reference so they link back to the applicant. NIC and phone numbers are kept as text.

Backup, restore and combine devices

The backup file keeps everything exactly as captured, including resource tables and capture references. Download a new backup after adding or editing records. To move data to another person, use a password-protected backup and give the password separately (by phone call, not in the same message).

After handover

When the files have been handed to the SARP PMU and checked, delete the data from this device.

Session setup

New entries start with this district and DS division; it can still be changed per applicant.

The age band is not yet approved by the PMU. Ages outside it are flagged for review, never blocked. Each device must use a different device code so capture references never clash.

Approved GN division list

The DS/GN audit list (DS_GN_audit.xlsx, 17 November 2026) is built in. The DS and GN dropdowns show only divisions on this list, with an Other (type) choice for anything not on it. To replace it with a newer list, load an Excel file in the same layout (one sheet per district: District and Province in rows 1–2, then DS division and GN name columns), or a sheet with four columns: District, DS division, GN number, GN name.
